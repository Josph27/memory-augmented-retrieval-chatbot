## Cross-cutting checks

- No sampled retain decision certifies safe execution. Real-composition ChatService tests can still resolve provider/local settings and environment-selected vector components despite temporary SQL/fake answer model.
- `app.py` module composition creates directories, resolves configuration and constructs Database. Module-scope app imports precede pytest fixtures.
- Native browser fixture exports temporary DATABASE_PATH/document Chroma path, but inherits environment, omits independent LONG_TERM_MEMORY_CHROMA_PERSIST_DIR and imports production app before service replacement. Better SQL isolation does not establish complete isolation.
- No global `tests/conftest.py` observed; `tests/e2e/conftest.py` attaches reports only. Pytest config sets Python path without an isolation hook.
- `braemon/package.json` has build/lint/dev/preview, no frontend test runner. Native browser/socket checks cannot establish React lifecycle parity.
