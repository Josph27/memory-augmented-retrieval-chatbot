## 1. Composition and selection

Core contract remains `MemoryCandidate[]` → rank/budget/select → `ContextPacket` → `ChatAgent`/model → memory update. Current `src/settings.py` is **canonical application configuration**, not the old provider file. Old provider responsibility moved to `src/provider_settings.py`. `AppConfig.load/from_env` reads canonical attributes plus specific env overrides; downstream constructors also read getenv. Env-only changes therefore do not universally change the composed app.

Default app orchestration is native; routing hybrid, reranker startup hybrid/CE blend, structured retrieval hybrid, gist generation enabled with LLM/deterministic fallback, memory policy scheduled. Explicit service/helper defaults and env-only evaluation composition can differ. `startup.py::main` selects reranker startup mode then starts Vite and execs Chainlit; run.sh wraps it. No Dockerfile/requirements entry remains. Direct Chainlit/.dev launch paths still exist.

No application disconnect callback guarantees End flush. Framework login/project-file/socket/edit/thread APIs remain version-dependent external entry points.
